## 来源

原始文件位于数据蛙录屏软件的录音输出目录：

```
C:\ProgramData\ShuJuWa\数据蛙录屏软件\RecOut\
```

磁盘上的扩展名是 `.keymp3`，软件界面显示为 `.mp3`——指的是同一个文件，不是两份。

## 转换说明

`.keymp3` **并非加密音频**。文件结构如下：

| 区间 | 内容 |
|---|---|
| `[0, 44)` | ID3v2.4 标签（含 `TSSE = "Lavf61.7.100"`） |
| `[44, 1004)` | Xing/VBR 头 + 前 2 个 MPEG 帧 |
| `[1004, EOF)` | 明文 MPEG-1 Layer III，48000 Hz，立体声 |

前 1004 字节被单字节 **XOR `0xCD`** 混淆。验证：首字节 `0x84 ^ 0xCD = 0x49 = 'I'`，异或后得到合法 `ID3` 头。

转换方式为**跳过前 1004 字节**，其余字节原样保留。代价仅是丢失 ID3 元数据与前 2 个 MPEG 帧（约 0.05 秒），音频内容无损。

## 校验

三个文件均通过 `ffmpeg -f null -` 解码验证，退出码 0，stderr 为空：

```
codec_name=mp3   sample_rate=48000   channels=2
```

| 文件 | 解码帧数 | 真实时长 |
|---|---:|---:|
| `Audio_261013145552.mp3` | 1,184 | 28.42 秒 |
| `Audio_261013182534.mp3` | 97,620 | 2,342.88 秒 |
| `Audio_261013145840.mp3` | 151,344 | 3,632.26 秒 |

> 提示：转换后的文件不含 Xing 头。个别播放器首次打开时会先扫描全量帧来计算时长，显示的时长会短暂偏大，属正常现象。
